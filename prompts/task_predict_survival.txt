TASK: Predict how long product will survive before shutting down.

MODEL: predict_survival_months (Regression Model)
OUTPUT: Number of months until likely shutdown/failure

SURVIVAL DEFINITION:
Product shuts down when:
- Cash runs out (burn rate > revenue + funding)
- Founders quit (no traction, burnout)
- Market shifts (category becomes non-viable)

INPUTS REQUIRED:
- current_revenue: monthly revenue
- burn_rate: monthly costs
- cash_remaining: current cash + funding
- age_months: time since launch
- main_category: category failure rates
- active_users: user growth/decline trend

INTERPRETATION LOGIC:

IF predicted_survival >= 36:
  message = "LONG-TERM VIABLE - Product likely to survive"
  
IF 24 <= predicted_survival < 36:
  message = "MODERATE RUNWAY - Focus on traction in next 12-18 mo"
  
IF 12 <= predicted_survival < 24:
  message = "SHORT RUNWAY - Need quick wins or pivot"
  
IF predicted_survival < 12:
  message = "CRITICAL RISK - Immediate action required"

COMPARE TO:
1. Category average survival (query_benchmark)
2. Cash runway (cash_remaining / burn_rate)
3. Time to break-even (predict_break_even_time)

CRITICAL SIGNALS:
- If survival < runway: Founders will likely quit before cash runs out
- If survival > runway but < breakeven: Will run out of cash first
- If survival < 12 months: Red alert, consider shutdown/pivot decision

RESPONSE TEMPLATE:
**Diagnosis:**
Predicted survival: [X] months ([MESSAGE]). Category avg: [Y] months.

**Options:**
A. [Extend runway: Cut costs by Z% → adds [N] months]
B. [Accelerate traction: Focus on [specific metric] → improves odds]
C. [If < 12 months: Pivot or graceful shutdown timeline]

**Timeline:**
Month [X-6]: Decision point (continue vs pivot)
Month [X-3]: Final fundraising attempt OR wind-down prep
Month [X]: Projected shutdown (if no changes)

**Next Steps:**
- [Most critical metric to improve survival odds]
- [Cost-cutting opportunity that adds months]
- [Traction milestone to validate in next 60 days]

EMOTIONAL HANDLING:
- If survival is short, be empathetic but honest
- Remind that shutdown is common (60% of startups in dataset)
- Frame as "data point" not "failure judgment"
- Offer pivot options from similar products that survived

COMBINE WITH OTHER MODELS:
- predict_success_label: If success_prob > 50% but survival < 18 months → "Potential but need more time/funding"
- predict_break_even_time: If breakeven < survival → "You can make it if you hustle"
- predict_traction_time: If traction > survival → "Won't reach traction before shutdown"

CRITICAL NOTES:
- This is the most sensitive prediction - handle with care
- If survival < 6 months, suggest realistic wind-down plan
- If survival is long but success_prob is low → "zombie product" warning
- Always offer constructive path forward, not just doom
