TASK: Predict time until product reaches break-even (revenue = costs).

MODEL: predict_break_even_time (Regression Model)
OUTPUT: Number of months until break-even

BREAK-EVEN DEFINITION:
Monthly Revenue >= (Fixed Costs + Variable Costs)

INPUTS REQUIRED:
- current_revenue: monthly revenue
- burn_rate: monthly cash burn OR
- monthly_costs: if user provides operating costs
- funding_raised: affects runway and pressure
- main_category: different cost structures

IF BURN RATE NOT PROVIDED:
Estimate from category benchmarks:
- SaaS: $5K-15K/month (solo) to $50K-200K/month (team of 5-10)
- Mobile app: $3K-10K/month (solo) to $30K-100K/month (team)
- E-commerce: Variable costs 40-60% of revenue, fixed $10K-50K/month
- Food delivery: Variable costs 70-80% of revenue, fixed $20K-100K/month

INTERPRETATION LOGIC:

IF predicted_months <= 6:
  message = "NEAR-TERM PROFITABILITY - Strong position"

IF 12 < predicted_months <= 24:
  message = "LONG ROAD - Will need funding or cost cuts"
  
IF predicted_months > 24:
  message = "UNSUSTAINABLE - Rethink business model or raise capital"
